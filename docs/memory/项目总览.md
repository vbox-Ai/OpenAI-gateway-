## 一、项目是什么

Agent2API 是一个 **AI 提供商聚合网关**：
- 把 30+ 家 AI 服务商（智谱清言、Trae、Kimi、MiniMax、CodeArts…）的
  账号、模型、余额、签到、凭证续期，统一到一个本地 HTTP 网关 + Web UI；
- 桌面端靠 Tauri（Windows / macOS / Linux）打包，移动端靠 Flutter 壳
  + Rust 静态库嵌 ipa（iOS），服务端有 Docker 镜像；
- 提供商分两类：
  - **内置 provider**：编译进网关本体（WorkBuddy、Accio、AutoClaw、
    Cline、Loomy、MonkeyCode、Qoder、ZCode、ModelScope + 自定义）；
  - **插件 provider**：通过 `plugin_host` 独立子进程、stdio 通信
    （小浣熊、CatPaw、Trae、CodeArts、OfficeAce、OrcaTerm、KukuAI、
    Command Code、Antigravity、智谱清言网页版…）。

## 三、各仓库怎么用

### 3.1 网关 `OpenAI-gateway-`

- **桌面端构建**：`desktop-tauri/` 下的 Tauri 壳，壳进程把
  `desktop-tauri/src-tauri/server/` 这个 Rust crate 作为库链接，
  网关以进程内 HTTP 服务器形式跑。
- **Docker / headless 服务器**：同一个 `agent2api-server` crate，
  独立二进制自建 Tokio 运行时。
- **iOS ipa 构建**（我们新增的）：单一 workflow
  `.github/workflows/ios-build.yml`：
  1. `cargo build --release --target aarch64-apple-ios --lib`
     → 产出 `libagent2api_server.a`；
  2. `flutter create .` + 回滚源码 + 拷贝 `.a` 到 `mobile-app/rust/`；
  3. 注入 ATS（放行本地回环）+ `UIFileSharingEnabled`（导出到
     Documents/Exports 可在「文件」App 里看到）；
  4. xcodeproj 直改 `OTHER_LDFLAGS`：
     `-Wl,-force_load,<.a> -Wl,-u,_agent2api_server_start`
     （防 dead-strip）；
  5. 编译插件 exe（`OpenAI-` 拉下来 `cargo build` aarch64-apple-ios
     → ldid entitlements 签名 → zip 进 `mobile-app/assets/plugins.zip`）；
  6. `xcodebuild` Release → 裸 `Runner.app` → 打 ipa → 上传 Releases。
- **关键 crate 路径**：
  - 网关核心：`desktop-tauri/src-tauri/server/`
  - FFI 入口：`.../server/src/lib.rs`（`run_headless` +
    `agent2api_server_start|stop|ping`）
  - 插件宿主：`.../server/src/server/core/plugin_host/`
    - `update.rs` — 插件索引 / 下载（`INDEX_REPO` 常量指向自建索引）
    - `lifecycle.rs` — spawn 与 iOS 自诊断
    - `packaging.rs` — 插件 zip 校验 / pack.json 解析
  - Web UI：`desktop-tauri/ui/`（纯 JS）
  - Flutter 壳：`mobile-app/lib/`（`main.dart` + `ffi.dart`）

### 3.2 原生插件 `OpenAI-`

- 29 家 provider 的 Rust 源码；
- 协议 crate `agent2api-provider-protocol` 从这里引用（网关 `Cargo.toml`
  里 `tag = "v3.3.0-beta.5.1"`）；
- 产出 `agent2api-providers` 单一可执行（29 家 provider 打在一个二进制里）；
- iOS 构建：`cargo build --target aarch64-apple-ios --bin agent2api-providers`；
- 插件包格式：`pack.json`（manifest）+ `bin/agent2api-providers` +
  可选 UI 资源。

### 3.3 网页插件 `OpenAI-web-`

- 承载「网页登录」形态的 provider（智谱清言网页版、DeepSeek 网页版等）；
- 同样用协议 crate，包名 `agent2api-web-providers`；
- CI workflow `ios-release.yml`（workflow_dispatch）→ iOS 构建 →
  ldid entitlements 签名 → zip → Release `web-v3.3.0-beta.5.1`。

### 3.4 自建插件索引 `Agent2plugin`

- `index.json` — 插件中心首页的卡片列表；
- `plugins/*.json` — 每个插件的 detail（release repo、tag 模板、资产模板、
  platforms 列表）；
- `plugins/agent2api-web-providers.json` 我们改过：`release.repo` →
  `vbox-Ai/OpenAI-web-`、`platforms` 加 `aarch64-apple-ios`；
- 网关从 `raw.githubusercontent.com/{INDEX_REPO}/main/` 拉取。

│  │ main.dart        ││
│  │ ffi.dart         ││ dart:ffi 绑定
│  └────────┬────────┘│
│           │          │
│  ┌────────▼────────┐│
│  │ libagent2api_    ││ Rust 静态库，-force_load 链进主二进制
│  │ server.a         ││ agent2api_server_start(dir, port)
│  │  ┌────────────┐  ││
│  │  │ agent2api-  │  ││ headless 网关（axum + tokio + rustls + SQLite）
│  │  │ server      │  ││
│  │  │  ├─ 内置    │  ││ 9 家 provider 编译进去
│  │  │  ├─ plugin_ │  ││ 拉起插件进程
│  │  │  │  host    │  ││ ← 当前卡在这里（spawn EPERM）
│  │  │  └─ Web UI  │  ││ 打包进 ipa 的 ui.zip
│  │  └────────────┘  ││
│  └─────────────────┘│
└─────────────────────┘
        │
        │ plugin_host::spawn()
        ▼
┌─────────────────────────┐
│ {Bundle}/plugins/       │  ← 构建时塞进 Runner.app，TrollStore 安装时重签
│   agent2api-providers   │  ← ldid entitlements 签名

## 七、工作流与 CI

|---|---|---|---|
| `iOS 构建与发布` | `OpenAI-gateway-` | `workflow_dispatch` | 裸 `.ipa`（Release tag `mobile-3.3.0-beta.5.1-buildN`，N = GITHUB_RUN_NUMBER，每次唯一） |

`Cargo.toml` / `mobile-app` / iOS workflow）→ 触发 `iOS 构建与发布` → 新 ipa。
