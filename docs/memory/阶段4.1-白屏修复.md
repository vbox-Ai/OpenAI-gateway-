# 阶段 4.1 — 白屏根因修复（服务起来就停）

## 现象

ipa 装到越狱机上，打开是纯白，但顶部状态条显示「服务已启动」。

## 根因

`server::start()` 的返回类型是 `Result<oneshot::Sender<()>, PortConflict>`，
这个 `Sender` **不是**「启动成功」的凭证，而是**停机开关**：

```rust
let (shutdown_tx, shutdown_rx) = oneshot::channel::<()>();
crate::spawn_task(async move {
    let _ = shutdown_rx.await;      // 发送端被 drop 也会立刻返回 Ok(Err)
    let _ = stop_tx.send(true);
});
```

`run_headless` 里原本是 `let _shutdown = server::start(&state)?;`，函数一返回，
`_shutdown` 出作用域被 drop → `shutdown_rx` 立刻 resolve → `stop_tx` 置位 →
`axum::serve` 的 graceful shutdown 触发 → 监听循环退出。

于是：`agent2api_server_start` 返回 0（bind 成功、serve 已 spawn），
Flutter 把状态条刷成「服务已启动」，但端口上已经没人接客 —— webview
请求 `127.0.0.1:3065` 拿到 connection refused，停在白屏且不会自己重试。

**这是「start 返回 0 ≠ 服务可用」的经典陷阱。**

## 修复

### Rust（`server/src/lib.rs`）

```rust
static SHUTDOWN: Mutex<Option<tokio::sync::oneshot::Sender<()>>> = Mutex::new(None);
```

- `run_headless` 把 `shutdown` 存进静态槽位，进程活多久句柄就活多久；
- 新增 `#[no_mangle] pub extern "C" fn agent2api_server_stop() -> i32`，
  供 Flutter 主动停机（幂等；0 = 已发出信号，1 = 本来就没在跑，2 = 槽位中毒）。

### Flutter（`mobile-app/lib/main.dart`）

1. **等 /health 再放 webview**：`start` 返回 0 只代表 bind 成功，监听任务在
   后台运行时里异步起来。改为轮询 `http://127.0.0.1:3065/health`（80 × 250ms），
   拿到 200 才创建 `InAppWebView`。否则首帧请求就是 connection refused，
   WKWebView 不会自动重试，白屏是必然。
2. **状态条进 SafeArea**：`Positioned(top: 0)` 会被状态栏的时钟压住，套
   `SafeArea(bottom: false)` 后落到灵动岛/时间下方。
3. **解压判据改判文件**：`ui/` 目录存在但 `index.html` 缺失（上次解压被杀）
   时也要重新解包，否则永远白屏。
4. **zip 条目名清洗**：去掉 `./` 前缀、前导 `/`，并做 zip-slip 归一化校验。
5. **失败可诊断**：启动码 1/2/3、/health 超时、页面加载 error 都写进状态条，
   带「重试」按钮（`stop()` 后再 `_setup()`）。

### CI（`.github/workflows/ios-build.yml`）

- `OTHER_LDFLAGS` 增加 `-Wl,-u,_agent2api_server_stop`（Dart 侧运行时 lookup）；
- 打包前加**产物校验**：`nm -gU Runner.app/Runner` 必须能看到三个
  `_agent2api_server_*` 符号，`flutter_assets/assets/ui.zip` 必须存在且含
  `index.html`。任一不满足直接 `::error::` 失败 —— 宁可构建红，不要发个白屏包。

## 记忆点

- `oneshot::Sender` 型停机柄 **drop = 停机**，任何「起服务」的 FFI 包装都
  必须把句柄存进 `static`；返回 0 只能代表 bind 成功。
- 「服务已启动」这类状态文案必须由外部探活（/health）确认后才可信。
