# 阶段 3.6 记忆点：run_headless + FFI 启动入口

## 完成内容
网关 headless 服务器（agent2api-server）现在可以作为**进程内库**在移动端启动：

- `server/src/lib.rs` 新增 `run_headless(data_dir: &str, port: u16) -> Result<(), String>`
  —— 与 `src/bin/agent2api-server.rs` 的 main() 同一条 bootstrap 时序：
  `bootstrap → set_ui_dir → attach_db → load_tokens → start`，但：
  · 绑回环 127.0.0.1（桌面语义，不做网络部署的 panel_gate / v1_fail_closed 闸门）
  · 不 block_on 等停机 —— 服务器由惰性全局运行时承接，函数返回后后台继续跑

- FFI 包装 `agent2api_server_start(data_dir: *const c_char, port: u16) -> i32`
  —— Flutter 侧调用，返回 0 = 成功，1/2/3 = 参数/UTF-8/启动失败

- `agent2api_server_ping() -> 42` 探活符号保留

## 验证结果
- `cargo check --target aarch64-apple-ios` → success
- `cargo build --release --target aarch64-apple-ios --lib` → success
- 产物 `libagent2api_server.a` ≈ 50 MB，含 18 家内置 provider + axum + rustls + SQLite + FFI 入口

## 关键判断（为什么这样能跑）
`server::start()` 内部用 `crate::spawn_task`（lib.rs 的全局运行时兜底），
所以从 FFI 同步上下文调用 `run_headless`，服务器会落到惰性全局多线程运行时上继续跑，
不需要调用方 block_on。
